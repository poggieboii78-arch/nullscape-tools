# Nullscape Tools

Private source repository for the Nullscape tool suite.

## Apps

- `apps/medal-pool` — Medal Pool Checker
- `apps/tools-home` — Nullscape Tools home
- `apps/altar-calculator` — Altar Price Calculator
- `apps/shop-calculator` — Shop Calculator
- `apps/tech-compendium` — Tech Compendium reader
- `apps/tech-compendium-editor` — Private Tech Compendium editor

The retired experimental scanner and screenshot collector are intentionally excluded.
